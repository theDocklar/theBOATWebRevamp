# Kohedha.lk — Events, Dining & Lifestyle Growth Engine

A dedicated SEO & Growth Intelligence Engine built for **Kohedha (`https://kohedha.lk`)** — Sri Lanka's premier restaurant & event discovery platform.

---

## ⚡ Quick Start Commands

```bash
# 1. Pull Live Google Search Console Ranking Queries for kohedha.lk
npm run kohedha:gsc

# 2. Mine Reddit (r/srilanka, r/colombo, r/travel) for Real Traveler & Local Questions
npm run kohedha:mine

# 3. Generate Human-First Lifestyle & Event Guides (Zero AI feel, direct app CTAs)
npm run kohedha:generate
```

## 🎯 3 Core Content Pillars for Kohedha

### 1. **Events & Nightlife in Colombo**
- Primary Keywords: `events in colombo`, `things to do in colombo this weekend`, `edm events sri lanka`, `colombo nightlife`.
- Target CTA: *"Download the Kohedha app to see upcoming live music lineups and book tickets."*

### 2. **Dining, Cafes & Food Festivals**
- Primary Keywords: `romantic dinner colombo`, `best cafes in colombo to work`, `food festival colombo`, `best street food colombo`.
- Target CTA: *"View live menus, table reservation numbers, and ratings on Kohedha."*

### 3. **Down South & Travel Experiences**
- Primary Keywords: `galle fort events`, `hiriketiya nightlife party`, `mirissa beach party`, `sri lanka travel itinerary`.
- Target CTA: *"Explore curated event guides across Galle, Mirissa, and Colombo on Kohedha."*

## 🛡️ Editorial & Indexation Standards
- **Zero Em-Dashes (`—`)**
- **Zero Bold Clutter (`**...**`)**
- **Hyper-Local Context**: Mentions exact neighborhoods (Kollupitiya, Bambalapitiya, Park Street Mews, Galle Face, Cinnamon Gardens).
- **Direct Links**: Links to `https://kohedha.lk` and `https://kohedha.lk/events`.
